Full credit for the original application, concept, and core implementation goes to:

- [thewh1teagle](https://github.com/thewh1teagle), original creator of Vibe
- The [Vibe repository](https://github.com/thewh1teagle/vibe) and its contributors

This fork keeps the original MIT license and builds on that work with custom behavior and branding changes for Sly.

## What Sly Changes

Sly currently adds and customizes:

- Sly branding and app identity
- Close-to-tray behavior
- Tray controls for showing, hiding, and quitting
- Improved hotkey record-and-transcribe behavior
- A dedicated in-app `Hide to tray` action
